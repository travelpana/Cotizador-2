---

### 1. Campo COUNTER

Simplificar la presentación del campo.

Actualmente el Counter se muestra dentro de un input con borde.

Modificar únicamente la interfaz.

Requisitos:

- Eliminar el borde, fondo y apariencia de input.
- Mostrar la información en una sola línea.
- Mantener el formato:

COUNTER: Jonathan

- La palabra "COUNTER" debe conservar el estilo actual.
- El nombre del counter debe mostrarse inmediatamente después de la etiqueta.
- Ambos deben estar alineados horizontalmente.
- Utilizar el mismo tamaño de fuente y el mismo peso tipográfico.
- El nombre del counter debe mostrarse en color azul para indicar que es editable.

Comportamiento:

- Al hacer clic sobre el nombre del counter, debe mantenerse exactamente el flujo de edición existente.
- Puede convertirse temporalmente en un input transparente o reutilizar el mecanismo actual.
- No cambiar la lógica de edición.

Comportamiento:
